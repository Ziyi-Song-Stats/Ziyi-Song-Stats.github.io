# ziyi-song-stats.github.io

Personal academic website of Ziyi Song, built by GitHub Pages (Jekyll).

## Where to edit

| What | File |
|---|---|
| Name, tagline, email, profile links, top menu | `_config.yml` |
| Publications (add `favorite: true` for a 🌺) | `_data/publications.yml` |
| About, Experience, Awards, Talks & Service, Teaching pages | `_pages/about.md`, `_pages/experience.md`, `_pages/awards.md`, `_pages/talks.md`, `_pages/teaching.md` |
| CV PDF | `files/Ziyi_Song_CV.pdf` |
| Profile photo (optional) | upload `images/profile.jpg` |
| Look and feel | `assets/css/style.css` |

Old addresses such as `/publications/`, `/activities/` and `/Awards/` redirect to the new pages.

## Preview locally

```bash
bundle exec jekyll serve
```
